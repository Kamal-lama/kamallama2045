## 🚀 Instant GitHub Pages Deployment

This website is developed using pure **HTML5, CSS3, and Vanilla JavaScript** with zero backend dependencies, making it directly executable and deployable via GitHub Pages in seconds:

1. **Push this repository** to GitHub.
2. In your repository on GitHub, navigate to **Settings** > **Pages** (under "Code and automation").
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`).
   - **Folder**: Select `/ (root)`.
4. Click **Save**.
5. Your portfolio will go live instantly at: `https://<your-username>.github.io/<repository-name>/`.
